ShadowRealm-OS update repository

This is the signed package feed for ShadowRealm-OS components and games. Software & Updates and APT use it automatically when checking for updates; available updates still need to be installed.

On ShadowRealm-OS, open Software & Updates, check for updates and install the available packages. You can also use the Terminal:

sudo apt update
sudo apt upgrade

The feed is already configured in the current installer image. Debian and other configured vendors continue to provide their own packages. This repository is intended for ShadowRealm-OS; do not add it to an unrelated distribution.
