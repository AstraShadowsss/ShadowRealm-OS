A familiar Linux desktop with a style of its own.

Built on Debian 13 and Xfce, ShadowRealm-OS brings applications, desktop controls and live status panels into one coordinated workspace. Try it from a USB drive or virtual machine before installing.

Make it yours

Coordinated styles, drag-and-drop dock editing, independent wallpapers and configurable background transparency. Native third-party application icons stay recognizable.

Everyday controls

Network, audio, Bluetooth, accounts, appearance and software tools. Movable widgets display resources, traffic, processes and privacy-service status. Optional widgets add a clock, calendar, local notes and a weather forecast.

Updates you control

Debian and configured vendors provide their updates. A signed repository supplies custom desktop components and nine offline games. Software & Updates shows available APT updates; Flatpak updates are separate.

Wallpapers, your way

Vivid cyberpunk Signature themes and a separate, unbranded Professional collection. Choose a collection, then browse its colors and wallpapers.

Appearance preview: the expanded collection is being prepared for the next desktop update.

Emerald, Ocean, Graphite and Plum accents pair with three sculpted abstract wallpapers. The same desktop controls and widgets use a restrained, unbranded appearance.

Before you install

This is a public beta. Back up your files, check the ISO checksum and test hardware from the live desktop. BIOS and UEFI installation paths are included; Secure Boot and dual-boot setups are not certified for this release. Optional disk encryption is configured during installation.
