A familiar Linux desktop with a style of its own.

Built on Debian 13 and Xfce, ShadowRealm-OS brings applications, desktop controls and live status panels into one coordinated workspace. Try it from a USB drive or virtual machine before installing.

Make it yours

Eight coordinated styles, editable dock shortcuts, independent wallpapers and configurable background transparency. Native third-party application icons stay recognizable.

Everyday controls

Network, audio, Bluetooth, accounts, appearance and software tools. The four desktop widgets show resources, traffic, processes and privacy-service status locally.

Updates you control

Debian and configured vendors provide their updates. A signed repository supplies custom desktop components and nine offline games. Software & Updates shows available APT updates; Flatpak updates are separate.

Before you install

This is a public beta. Back up your files, check the ISO checksum and test hardware from the live desktop. BIOS and UEFI installation paths are included; Secure Boot and dual-boot setups are not certified for this release. Optional disk encryption is configured during installation.
