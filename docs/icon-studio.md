# Shadow Icon Studio

Shadow Icon Studio creates and restores application icons for the ShadowRealm-OS desktop. Open it from the application menu or from **Appearance → Icons & Dock**.

Creating icons and applying them to your own account needs no network connection and no administrator access.

## Create

1. Choose artwork: import a PNG, JPEG, SVG or WebP file, drag one onto the window, or load the artwork already installed for an application.
2. Select the application the icon belongs to. Search the installed applications in the visible list and select an entry explicitly.
3. Review the twelve palette previews. The original colours are kept by default; a fixed tint is optional.
4. Apply the icon, or export it.

The single large preview shows the current palette. Applying writes the icon to the selected application for the current account only.

## Batch and packs

- Export up to 100 source files in one operation, in SVG and the eight standard PNG sizes.
- Open the last export folder, or choose a different destination. The default is `Documents/ShadowRealm Icons`.
- Export your custom logos as a pack and import a pack on another account or machine. Importing asks before replacing existing artwork.
- Restore one application, or restore every eligible installed application at once. Applications that are missing, protected or no longer installed are skipped.

A pack is a set of your own custom logos. It is not a software installer and does not add applications.

## My Icons

Named personal icons are stored separately from the overrides applied to installed applications. Saving a creation in My Icons does not change any application until you apply it.

## User guide

The built-in **User guide** tab repeats these steps inside the application.

## Icon catalog

The desktop ships an application catalog of 3,483 entries. It contains identifiers and aliases only — no artwork.

Icon artwork is read from the applications already installed on the machine, then drawn into the desktop's icon frame. No third-party application logos are distributed with ShadowRealm-OS. Applications without a catalog entry keep their own icons.

Catalog coverage counts identifiers, not a visual review of every application logo.

## Export and restore

Exported icons are ordinary SVG and PNG files you can keep, copy or use elsewhere. Exported artwork may be raster.

Restoring an application returns it to the icon supplied by its package.

## Recovery

If an icon looks wrong after applying it, restore that application from the same window. To return the whole set to the packaged artwork, restore all eligible applications.
