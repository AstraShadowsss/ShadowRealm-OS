# System requirements

This release targets 64-bit x86 PCs (AMD64/x86-64), including compatible Intel processors.

| Item | Practical starting point |
| --- | --- |
| CPU | 64-bit x86 processor, 2 cores recommended |
| RAM | 4 GB recommended; VM checks also used 3 GB |
| Disk | 32 GB virtual/test disk; 40 GB or more recommended for regular use |
| Display | 1280 × 720 or greater recommended for the full custom desktop |
| USB installer | 8 GB or larger drive |
| Firmware | BIOS or UEFI; Secure Boot not certified for this beta |
| Network | Needed for updates, Flatpak downloads and online applications |

These are practical recommendations, not measured universal minimums. Browsers, office documents and games may need more resources. Leave additional host RAM and disk space available when running a VM.

The image includes the Debian kernel, common firmware and desktop hardware services. Hardware support still depends on the exact GPU, Wi-Fi chipset, Bluetooth adapter and firmware. Proprietary graphics-driver setup and every laptop's power-management behavior have not been tested. No physical-device compatibility certification is claimed.
