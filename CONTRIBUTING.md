# Contributing

Open a GitHub issue for a reproducible bug or a proposed change. Include the release filename, hardware or VM configuration, steps to reproduce and the expected result. Remove passwords, personal files and network credentials from logs and screenshots.

For code changes, keep patches focused and explain how they were checked. Test privileged helpers, account changes and installer work only in disposable systems. Preserve native application icons and existing upstream attribution. Keep the SR logo geometry and ShadowRealm-OS spelling consistent across palettes.

Original contributions should use the project's MIT terms where applicable. Changes to third-party-derived code remain subject to its existing license. Never commit ISO/VM images, private keys, personal profiles or generated build directories.
